# TCPC Phantom Study

Companion materials for the TCPC phantom study.

- [Geometries](geometries/): the three original lumen meshes (STL, millimetres).
- [Hardware](hardware/): apparatus and fabrication files.
- [Simulation](simulation/): study-specific code and configurations.
- [Processing](processing/): analysis and figure scripts.
- [Supplement](supplement/): supporting figures and tables.

The geometry files are available; the remaining materials will be added.
